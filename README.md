# Altima — Construction Company Landing

📌 **Description**  
Responsive one-page website for a construction company. The goal was to transform a vague brief into a clean, structured landing page with sections for services, projects, and contacts.

🛠 **Tech stack**  
- HTML5  
- CSS3 (responsive, mobile-first)  
- Basic JavaScript (navigation, interactions)

👩‍💻 **My role**  
- Built structure and responsive layout from scratch  
- Styled components and ensured consistent typography/colors  
- Added small JS hooks for interactivity  
- Optimized assets for faster loading

🚀 **How to run**  
Open `index.html` locally in a browser, or view via GitHub Pages once enabled.  


💡 **What I learned**  
- How to clarify unclear requirements and turn them into page structure  
- Practicing mobile-first responsive CSS  
- Creating maintainable, clean HTML/CSS  
- Adding accessibility basics (headings, alt-text, focus states)

🔜 **Next steps**  
- Improve accessibility (aria-labels, keyboard navigation)  
- Minify CSS and assets for production use  
- Add contact form with basic validation
